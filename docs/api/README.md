# API

API mobile dùng prefix:

```text
/api/v1
```

Nhóm API tối thiểu:

- Auth: đăng nhập, đăng xuất, thông tin tài khoản.
- Tasks: danh sách việc, chi tiết việc, bắt đầu làm.
- Attendance: điểm danh GPS + selfie.
- Reports: gửi báo cáo hoàn thành bằng ảnh.
- Notifications: danh sách thông báo, đánh dấu đã đọc.
